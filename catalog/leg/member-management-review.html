Critical Gaps

Data Export (Right of Access)

Missing

POPIA Section 23 and GDPR Article 15 require providing data subjects with a copy of their personal data. No property currently has a data export endpoint.

Required: GET /api/privacy/data-export returning JSON of all user data.

Account Deletion (Right to Erasure)

Missing

POPIA Section 24 and GDPR Article 17 require deletion on request. No property has a deletion flow. 2nth.me mentions it in terms but hasn't built it.

Required: POST /api/privacy/delete-account with confirmation email.

Consent Records

Partial

2nth.ai captures consent_at and consent_ip on registration. Other properties capture nothing. No granular consent types (marketing, profiling, etc.).

Required: consent_records table with per-property, per-type tracking.

Privacy Notices

Partial

Only 2nth.me has a comprehensive privacy page. 2nth.ai has partner terms but no standalone privacy notice. Other properties have nothing.

Required: /privacy page on every property.

Breach Register

Missing

POPIA Section 22 requires maintaining a breach register and notifying the Information Regulator within 72 hours. No schema or workflow exists.

Data Retention Enforcement

Missing

Activity logs, anonymous fingerprints, and expired tokens accumulate indefinitely. No scheduled purge worker exists.

Proposed D1 Schema Changes

Migration: 0009_privacy_compliance.sql

-- Consent records (per user, per property, per type)
CREATE TABLE IF NOT EXISTS consent_records (
    id              TEXT PRIMARY KEY,
    user_id         TEXT NOT NULL REFERENCES users(id),
    property        TEXT NOT NULL,
    consent_type    TEXT NOT NULL,
    granted         INTEGER NOT NULL DEFAULT 1,
    ip_address      TEXT,
    user_agent      TEXT,
    granted_at      TEXT NOT NULL DEFAULT (datetime('now')),
    revoked_at      TEXT,
    terms_version   TEXT,
    UNIQUE(user_id, property, consent_type)
);

-- Consent change audit trail
CREATE TABLE IF NOT EXISTS consent_audit (
    id              TEXT PRIMARY KEY,
    user_id         TEXT NOT NULL,
    property        TEXT NOT NULL,
    consent_type    TEXT NOT NULL,
    action          TEXT NOT NULL,
    old_value       INTEGER,
    new_value       INTEGER NOT NULL,
    ip_address      TEXT,
    user_agent      TEXT,
    created_at      TEXT NOT NULL DEFAULT (datetime('now'))
);

-- Breach register
CREATE TABLE IF NOT EXISTS breach_register (
    id              TEXT PRIMARY KEY,
    detected_at     TEXT NOT NULL,
    description     TEXT NOT NULL,
    affected_users  INTEGER,
    data_types      TEXT,
    severity        TEXT,
    contained_at    TEXT,
    regulator_notified_at TEXT,
    users_notified_at TEXT,
    remediation     TEXT,
    status          TEXT NOT NULL DEFAULT 'open',
    created_at      TEXT NOT NULL DEFAULT (datetime('now'))
);

-- Data subject requests (30-day SLA tracking)
CREATE TABLE IF NOT EXISTS data_requests (
    id              TEXT PRIMARY KEY,
    user_id         TEXT NOT NULL REFERENCES users(id),
    request_type    TEXT NOT NULL,
    status          TEXT NOT NULL DEFAULT 'pending',
    requested_at    TEXT NOT NULL DEFAULT (datetime('now')),
    acknowledged_at TEXT,
    completed_at    TEXT,
    sla_deadline    TEXT NOT NULL,
    notes           TEXT
);

-- Index for quick lookups
CREATE INDEX IF NOT EXISTS idx_consent_user ON consent_records(user_id);
CREATE INDEX IF NOT EXISTS idx_consent_audit_user ON consent_audit(user_id);
CREATE INDEX IF NOT EXISTS idx_data_requests_user ON data_requests(user_id);
CREATE INDEX IF NOT EXISTS idx_data_requests_status ON data_requests(status);
